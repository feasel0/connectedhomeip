### Static Numeric Companion Defect

`_generate_valid_command_field_value` recognizes the primitive numeric types but returns a value only for a minimum, a negative maximum or an allowed-value set. A field with only a nonnegative static maximum falls through to None. Actual Matter 1.7 examples are Color Control Hue (maximum 254), TransitionTime (65534), General Diagnostics Count (2048), and Scenes SceneID/TransitionTime (254/60000000). Zero is legal in each case.

The owning-file regression uses those five real parsed fields. Against the unchanged generator it executes and fails in all five subcases with `None != 0`; this is intended behavioral red evidence. After the three-line static-case correction it passes. Ten controls add unresolved minimum/maximum references to those same fields and require None rather than a guessed value. Existing OnWithTimedOff bounded-sibling skip, DEM invalid-bound, strict incomplete-coverage and no-representable-violation controls remain intact.

No exact number of repaired integration paths is claimed. An exploratory all-path metadata join did not complete reliably across XML/generated field naming and object-shape differences; its failed attempts are not accepted as a post-fix coverage tally or a test execution. The validated evidence is the real-field red/green regression and the full owning suites, not a fresh integration rerun.

### Remaining Setup And Expression Gaps

The static correction does not add numeric aliases or resolve all sibling bounds. Actual failing aliases include group-id, TLSCAID and TLSCCDID; the numeric helper does not recognize them. Color-temperature companions also have unresolved setup/bound requirements. Generating a number of the correct wire type does not by itself prove the referenced group/certificate/endpoint exists or is otherwise valid.

SetVolume.UnmutePolicy fails while its required Volume sibling retains raw `minOf(MaxDeviceVolume, MaxUserVolume)` metadata. Supported target-field resolution is not the same as resolving a required sibling. IncreaseVolume and DecreaseVolume contain a nested subtraction of MinDeviceVolume from that minimum. These remain unsupported. No general expression engine, denylist exclusion or fake rejection was added.

### Certificate Encoding Limit

The actual field is octstr with maximum length 3000. Its generated violating payload is **3001 bytes**. The reported source line, `TLVPacketBufferBackingStore.cpp:91`, is the return from `GetNewBuffer` when `mUseChainedBuffers` is false. It is not the later allocation-failure branch.

This positively identifies a local single-buffer/chaining encoding boundary. It does not prove DUT heap exhaustion, network delivery or remote constraint processing. An encodable transport/probe strategy is needed before this path can establish server rejection; skipping the path or fabricating a status is not a correction.
