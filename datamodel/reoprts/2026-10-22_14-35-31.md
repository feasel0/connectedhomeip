## Concrete Dependency Traces

### ModeBase and Parser

`ModeBase::Instance::Init()` constructs `CodegenModeBaseCluster` and registers it
with the CodegenDataModelProvider registry; that class uses ModeBaseCluster.
Thus existing codegen applications using this bridge can reach the tested
implementation; the bug is not isolated to a unit-test-only class. Which SVE
devices use it is still unverified. Ordinary-mode command metadata must retain
Operate, while Thermostat's two commands use its own generated Manage metadata.
Administrator-based functional tests can pass without checking that boundary.

The parser path is DUT SpecificationVersion -> prebuilt model ZIP ->
`build_xml_clusters()` -> derived-command merge -> conformance/field metadata.
`device_conformance_tests.py` compares accepted/generated command lists with
the parsed conformance and reports missing mandatory or forbidden commands.
IDM field discovery also uses parsed command fields. Thermostat Mode overrides
IDs 0x00, 0x01 and 0x02 without explicit conformance/direction; their base
mandatory/feature conformance and fields must survive, while explicit Manage
must remain. Oven/RVC Operational State supply similar missing/explicit
overlays; explicit Microwave and Refrigerator exclusions must not be replaced
with mandatory base definitions.

No direct certification consumer of `XmlCommand.privilege` was found in the
inspected infrastructure beyond representation/errata tests. Therefore the
runtime ACL defect and parser privilege representation are not conflated.
The inspected Thermostat functional scripts establish possible command use,
not an accepted event ACL test list or an Operate/Manage negative test.

### Closure and EPA Minimal Independent Scope

For Closure, retain the preserved recoverable Positioning-configuration check
and constructor admission before delegate side effects: Resolution/StepValue
must lie within their allowed percent100ths range and StepValue must be an
integer multiple of Resolution. Essential existing-fixture tests are zero and
out-of-range values, nonmultiple step, valid 1/1 and nontrivial multiples,
disabled-Positioning behavior and absence of side effects on admission failure.
Do not automatically import all 47 tests. The model's fixed defaults are already
1/1; do not claim ordinary defaults divide by zero or use a new clamp policy.

For EPA, the preserved proposal checks eight present rating members for their
minimum while retaining feature-disabled, absent and nullable values. Essential
tests are invalid present zero, valid minimum/upper values and absent/null/
disabled-feature controls through actual construction/readback. Current upstream
has since moved EPA onto AlarmBase; port the minimal guard to that architecture
and rerun both negative and positive controls before presenting it as current
mergeable evidence. Do not restore old alarm-state code or all 321 test lines.

Neither correction is confirmed required for SVE until the actual selected
device/test inputs show exposure. If required tests already pass with valid
fixed configuration, that does not prove the general validation defect absent;
it simply does not establish a deadline merge dependency.

### IDM and DEM: Smallest Correct Disposition

The unchanged baseline TC_IDM_9_1 still fails accepted violations and a run with
no exercised constraint at all. It can also skip unbuildable fields. Its
SpecificationVersion >=1.7 policy is concrete, but the event's test package and
cluster list are missing. fd4843c's full strict-coverage gate additionally turned
local limitations into a blanket failure; **do not restore that gate unchanged**.

The preserved failing integration has 56 field paths: 43 invalid/unbuildable
required siblings, three Audio Control expressions, nine enum-status paths and
one local encoding limit. These are diagnostic categories, not 56 DUT defects.

- Use the minimal static numeric sibling correction where zero is provably
  valid. Unresolved references and group/certificate aliases still require
  semantically valid setup, not a guessed integer.
- Preserve and evaluate the required DEM field/attribute maxOf and supported
  numeric minOf/maxOf forms in the real consumer. Sibling expressions and nested
  subtraction are separate missing capabilities. Rejecting unsupported forms
  is explicit but is not adequate execution of a required certification test.
- Preserve proof of accepted invalid values as DUT failures. Report unsupported
  generation/encoding as harness-blocked/incomplete, retain the exact untested
  path, and require a test-owner disposition or a working probe. Do not silently
  credit it as tested or infer remote enforcement from no I/O.
- The 3001-byte certificate probe reaches the local non-chained buffer limit,
  not a demonstrated DUT allocation failure. The smallest eligible remedy is
  an encodable violating probe/transport with evidence it actually reaches the
  DUT, or a formal test-owner limitation/alternate-case decision.
- Undefined-enum InvalidCommand versus generic ConstraintError needs the
  cluster/test-plan owner contract decision. Do not broaden accepted statuses
  or patch devices solely to green a harness gate.
