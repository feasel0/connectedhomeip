## Root Causes And Corrections

### Storage Integrity

TransportOptionsStorage constructs TransportTriggerOptionsStorage through its decodable assignment. The latter previously retained MotionZones only for Motion, clearing the optional for AmbientContext even after successful admission. Null, present-empty and populated AmbientContext values were all lost before response encoding, CurrentConnections persistence and later reload.

The correction expands only that existing guard to **Motion or AmbientContext**. Existing vector ownership and deep-copy rebinding are reused. Continuous and Command do not begin retaining prohibited fields. No broad storage refactor, generated definition change or fallible-assignment API is introduced. An existing comment is corrected to identify allocation's validation boundary rather than claiming the earlier Motion-only validator always checked AmbientContext.

### Malformed Inner Elements

DecodableList::ComputeSize counts TLV entries but does not establish that each TransportZoneOptionsStruct decodes. Iterator::Next returns false for either end-of-list or a decode error. The allocation loop ignored ComputeSize's result and both iterators' statuses, allowing AmbientContext to proceed with a partial or empty decoded prefix.

Allocation now returns **InvalidCommand** on a failed size computation, duplicate-check iterator status or zone-validation iterator status. These checks occur before constructing transport storage, calling AllocatePushTransport on the delegate or inserting/persisting a connection. Existing duplicate, maximum-list-size and invalid-zone statuses remain unchanged for their existing validly decoded inputs.

Motion was investigated rather than assumed defective: its earlier ValidateIncomingTransportOptions branch already checks the element iterator and rejects these malformed structs. That behavior remains unchanged; the shared downstream allocation loop is now checked for both trigger types. Infallible storage conversion still expects validated input; this is not general hardening of arbitrary corrupted persisted data or every storage caller.
