## Usage And Limitations

Run `~/transcription/RUN_UBUNTU.sh` in a terminal. The implementation prompts for
an API key without saving it and writes the generated Markdown in the kit's
directory. Existing `OPENAI_API_KEY` environment configuration is also supported.
No pip packages, virtual environment, FFmpeg, or conversion are required.

No real transcription API call was made, no API credentials were obtained,
and no recording was uploaded. Live model access, account billing, network
connectivity, and transcription quality therefore remain unverified. Starting
the script will upload audio and may incur API charges.
